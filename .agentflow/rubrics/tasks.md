# Рубрика: tasks

## Обязательные проверки

- `TASKS-COVERAGE` — каждое требование specs реализуется хотя бы одной задачей.
- `TASKS-FORMAT` — группы `## N. Название`, задачи `- [ ] N.M описание`; галочки не проставлены.
- `TASKS-VERIFY` — у каждой задачи указан способ проверки (тест, команда, наблюдаемое поведение).
- `TASKS-BATCH` — группа = один task batch из 1-4 задач, порядок групп по зависимостям; acceptance-тесты не запланированы.

## На что ещё смотреть

- Тесты и документация идут в той же группе, что и код, а не отдельной финальной группой.
- Нет задач вне scope proposal.
