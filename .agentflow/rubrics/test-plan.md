# Рубрика: test-plan

## Обязательные проверки

- `TP-COVERAGE` — каждый `#### Scenario:` из specs есть в таблице сценариев.
- `TP-NEGATIVE` — негативные случаи, которые следуют из specs, включены.
- `TP-EXECUTABLE` — шаги и ожидаемые результаты конкретны: тест можно написать, не читая реализацию.
- `TP-EVIDENCE` — для каждого сценария указано, какое доказательство сохраняется в каталоге evidence acceptance-тестов.

## На что ещё смотреть

- Environment объясняет, как импортировать или запустить систему.
- Manual check — 2-5 шагов для человека.
