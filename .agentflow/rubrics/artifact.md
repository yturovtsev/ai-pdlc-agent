# Рубрика: артефакт схемы без своей рубрики

Общая рубрика для артефактов, у которых нет файла `<id>.md` ни в `.agentflow/rubrics/` репозитория,
ни в kit (например, артефакты корпоративной схемы). Главный критерий — инструкция и шаблон схемы
OpenSpec для этого артефакта: путь к ним дан в задаче. Своя рубрика артефакта кладётся в
`.agentflow/rubrics/<id>.md` целевого репозитория.

## Обязательные проверки

- `ART-INSTRUCTION` — артефакт выполняет инструкцию и шаблон схемы: все требуемые разделы есть и заполнены по существу.
- `ART-INTENT` — содержание соответствует intent пользователя и уточнениям, scope не расширен.
- `ART-UPSTREAM` — артефакт согласован с принятыми upstream-артефактами и не противоречит им.
- `ART-VERIFIABLE` — утверждения конкретны и проверяемы; нет неподтверждённых допущений без пометки.

## На что ещё смотреть

- Реализуемость в текущем репозитории (проверено по коду).
- Продуктовые развилки помечены needsHuman.
