# Рубрика: proposal

Общая для spec-author и spec-reviewer. Ревьюер возвращает каждую обязательную проверку в `checks[]`.

## Обязательные проверки

- `PROPOSAL-INTENT` — Why и What Changes соответствуют intent пользователя и уточнениям, ничего не потеряно.
- `PROPOSAL-SCOPE` — scope не шире intent; явно перечислено, что вне scope.
- `PROPOSAL-CAPABILITIES` — каждая capability названа по устойчивому поведению, а не по задаче; есть хотя бы одна новая или изменённая.
- `PROPOSAL-IMPACT` — Impact называет реально затронутые модули репозитория (проверено по коду).
