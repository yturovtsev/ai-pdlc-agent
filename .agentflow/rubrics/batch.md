# Рубрика: ревью task batch

## Обязательные проверки

- `CODE-SPEC` — каждое требование и сценарий батча реализованы; нет поведения вне спеки.
- `CODE-TESTS` — unit-тесты из сценариев проверяют поведение и проходят; тесты не ослаблены.
- `CODE-GATES` — гейты батча зелёные (красный гейт — critical).
- `CODE-SCOPE` — изменены только файлы, нужные задачам батча; спека и защищённые пути не тронуты.
- `CODE-QUALITY` — корректность, граничные случаи, обработка ошибок, читаемость.

Поля `specCompliance` и `codeQuality` обязательны: `{ "result": "PASS|FAIL|NOT_VERIFIED", "summary": "..." }`.
