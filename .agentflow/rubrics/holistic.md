# Рубрика: сквозное ревью спеки

Проверяется весь пакет change целиком после того, как каждый артефакт прошёл своё ревью.
Каждая блокирующая находка указывает в поле `artifact`, какой артефакт исправлять.

## Обязательные проверки

- `HOL-INTENT` — пакет в целом реализует intent и уточнения пользователя, без расширения scope.
- `HOL-CONSISTENCY` — proposal, specs, design, test-plan и tasks не противоречат друг другу.
- `HOL-TRACE` — цепочка intent → requirement → scenario → test-plan → task не рвётся ни на одном требовании.
- `HOL-READY` — по пакету можно реализовать и принять change без вопросов к автору; открытые продуктовые развилки помечены needsHuman.
