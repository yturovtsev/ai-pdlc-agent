# Spec Delta

## ADDED Requirements

### Requirement: Автопилот до ревью человека
С флагом `agentflow run --auto-until-review` контроллер SHALL выбирать каждое решение человека до приёмки change так же, как с `--auto-approve`: рекомендуемый вариант и текст по умолчанию. Диалог «Принять change?» автопилот SHALL NOT решать. Флаг вместе с `--auto-approve` SHALL останавливать запуск до создания ветки с сообщением, что флаги несовместимы.

#### Scenario: Спека и код без человека
- **WHEN** выполняется `agentflow run tasks/01-slugify.md --mock --auto-until-review`
- **THEN** уточнение intent, ревью каждого артефакта и freeze проходят без ввода человека, в логе у каждого решения отметка автопилота, батчи, acceptance и финальное ревью выполняются

#### Scenario: Оба флага
- **WHEN** выполняется `agentflow run tasks/01-slugify.md --auto-approve --auto-until-review`
- **THEN** run не создаётся, ветки и worktree нет, сообщение называет оба флага как несовместимые

### Requirement: Автопилот не снимает блокирующие находки
В режиме `--auto-until-review` автопилот SHALL NOT выбирать waiver и «Всё равно перейти дальше», в том числе по рекомендации и по точке `--inject proceed:<петля>`. Вместо рекомендованного waiver он SHALL выбирать ещё раунд исправлений, а лог SHALL называть причину замены. Остальные рекомендации, включая «Остановить» на третьем исчерпании, автопилот SHALL выбирать как есть.

#### Scenario: Автор оспорил все находки
- **WHEN** у артефакта исчерпаны автоматические раунды, автор оспорил все находки ревьюера и рекомендован waiver
- **THEN** автопилот выбирает ещё раунд spec-author, лог называет замену waiver, находки остаются открытыми

#### Scenario: Находки не сходятся
- **WHEN** находки сквозного ревью остаются после трёх исчерпаний лимита
- **THEN** run переходит в BLOCKED, ни одна находка не снята, в отчёте приёмки раздел waiver пуст

#### Scenario: Точка перехода дальше
- **WHEN** run идёт с `--auto-until-review --inject proceed:batch:1`, а батч 1 исчерпал раунды
- **THEN** «Всё равно перейти дальше» не выбран, лог сообщает, что режим не переходит дальше, батч не засчитан решением человека

### Requirement: Передача решений человеку
Когда run в режиме `--auto-until-review` паркуется на приёмке или останавливается в BLOCKED, контроллер SHALL записать в `state.json` время и причину передачи, и с этого момента все решения этого run SHALL принимать человек, включая решения после `agentflow resume`. После падения контроллера или убитого процесса без передачи resume SHALL продолжать с автопилотом.

#### Scenario: Resume после BLOCKED
- **WHEN** run в режиме остановлен в BLOCKED блокером ревью батча 1, затем в TTY выполняется `agentflow resume <run-id>`
- **THEN** каждое следующее решение run, включая «Принять change?», ждёт выбора человека, run не паркуется

#### Scenario: Resume после убитого контроллера
- **WHEN** run в режиме убит после этапа spec (`--inject kill-after:spec`), затем выполняется `agentflow resume <run-id>`
- **THEN** решения apply выбирает автопилот, run паркуется на приёмке
