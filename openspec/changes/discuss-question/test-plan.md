# Test Plan

## Scope

Capability `human-decisions`:

- «Диалог выбора» (MODIFIED): «Выбор по Enter» (регрессия), «Пункты вопроса автора».
- «Обсуждение вопроса с ролью»: «Уточнение последствий варианта», «Вторая реплика помнит первую»,
  «Реплика только читает», «Пустой текст».
- «Уточнение вариантов в обсуждении»: «Роль добавила вариант», «Ответ текстом без JSON».
- «Переписка обсуждения в решении»: «Ответ после обсуждения», «Resume посреди обсуждения».
- «Лимит реплик обсуждения»: «Шестая реплика», «Продолжить после лимита».
- «Сбой реплики обсуждения»: «CLI упал на реплике», «Реплика молчит».
- «Обсуждение и автопилот»: «Вопрос при автопилоте».

Capability `pipeline-orchestration`:

- «Проверка без моделей» (MODIFIED): «Все петли на mock-ролях», «Обсуждение вопроса на mock-ролях».

## Environment

- Kit с зависимостями (`npm install`), Node ≥ 22.13.
- **Офлайн-модули.** Тест `e2e/discuss-question.test.js` (node:test) импортирует модули контроллера
  через tsx (`node --import tsx --test e2e/discuss-question.test.js`):
  - `tools/agentflow/human.ts` — `new Human(false, io)`, где `io` — сценарий: `select` отдаёт
    заранее заданные ключи по очереди и запоминает переданные варианты меню, `input` отдаёт
    заданные строки, `tty` → true. `question(q, discuss)` с заглушкой `reply`, которая
    запоминает аргументы и отвечает по сценарию (ответ, ответ с вариантами, `{ error }`);
  - `tools/agentflow/context-builder.ts` — промпт реплики обсуждения и разбор её ответа
    (экспортируемые функции, имена — по коду);
  - `tools/agentflow/roles.ts` — `decideAcl` с `readOnly: true`.
- **Mock-прогоны.** Копия kit с `git init` и начальным коммитом (mock создаёт ветку и worktree).
  Команда: `node tools/agentflow/bin/agentflow.mjs run tasks/01-slugify.md --mock --auto-approve --inject <точки>`,
  stdout в файл, stdin из `/dev/null`. Журнал — `.agentflow-runs/<run>/events.jsonl`, run id из
  вывода; контексты ролей — в `contexts/` каталога run.
- **Сбой реплики** снаружи mock-прогоном не воспроизводится: mock-роль не падает. Он проверяется на
  уровне `Human` со сценарием `io` и заглушкой `reply`, которая отдаёт `{ error }`.
- **Интерактивные сценарии** — псевдотерминал `e2e/helpers/pty-run.py` (`pty.fork`, 30×120,
  запуск `python3 -I`, клавиши по таймеру). Если хелпера нет, его создаёт acceptance-tester.

## Manual check

1. На gigacode запустить run с неполным intent (`tasks/03-incomplete.md`). На вопросе шага уточнений
   выбрать «Обсудить / уточнить…» и спросить о последствиях варианта. Ответ роли по существу,
   меню вопроса появилось снова.
2. Попросить роль предложить вариант, которого нет в списке. Меню показывает новый вариант, в логе
   отмечено, что варианты обновлены.
3. Выбрать вариант и открыть промпт следующей роли в `contexts/`: в уточнениях есть переписка.
4. Нажать Ctrl+C во время ответа роли в обсуждении: терминал восстановлен, run продолжается `agentflow resume`.
