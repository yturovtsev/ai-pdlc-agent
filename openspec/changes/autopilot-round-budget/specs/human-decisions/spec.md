# Spec Delta

## MODIFIED Requirements

### Requirement: Диалог при исчерпании лимита
Когда кончились автоматические раунды (артефакт 3, сквозное ревью 3, батч 3, финал 2, серия повторов при сбое CLI), контроллер SHALL открывать диалог с вариантами для этой петли: ещё раунд, указание роли, исправлю сам, новый implementer, waiver, вернуться к спеке, остановить. На автопилоте петли артефакта и сквозного ревью SHALL проходить по лимиту раундов без диалога. Исключение — последняя правка артефакта с ошибкой валидации OpenSpec.

#### Scenario: Артефакт не сходится
- **WHEN** у артефакта три раунда подряд REVISE, run идёт без автопилота
- **THEN** открывается диалог исчерпания со списком оставшихся находок

#### Scenario: Артефакт не сходится на автопилоте
- **WHEN** у артефакта три раунда подряд REVISE, run идёт с `--auto-approve`
- **THEN** диалога исчерпания нет: spec-author правит артефакт последний раз, артефакт принят без повторного ревью
