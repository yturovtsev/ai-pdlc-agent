# Test Plan

## Scope

Capability `pipeline-orchestration`:

- «Раскрытие размышления по клику»: «Раскрыть кликом», «Свернуть повторным кликом», «Клик мимо
  размышления», «Лог продолжается под раскрытым размышлением».
- «Длинное размышление при раскрытии»: «Текст не помещается», «Строка у верхнего края».
- «Режим мыши во время прогона»: «Вывод в файл», «Флаг отключения», «Ctrl+C в режиме мыши».
- «Колесо мыши в режиме мыши»: «Прокрутка истории колесом».
- «Размышления после диалога и изменения размера окна»: «После диалога», «После изменения размера окна».
- «Панель не мешает диалогам» (MODIFIED): «Диалог исчерпания лимита» (регрессия), «Клик во время диалога».
- «Терминал восстанавливается на выходе» (MODIFIED): «Ctrl+C во время работы субагента» и «Изменение
  размера окна» (регрессия), «Выход из режима мыши».
- «Проверка без моделей» (MODIFIED): «Все петли на mock-ролях» и «Обсуждение вопроса на mock-ролях»
  (регрессия), «Долгое размышление на mock-ролях».

## Environment

- Kit с зависимостями (`npm install`), Node ≥ 22.13, Python 3.
- **Эмулятор экрана `e2e/helpers/vt.js`.** Если его нет, его создаёт acceptance-tester. Эмулятор держит
  сетку `rows×columns`, историю (строки, ушедшие за верх области с верхней строкой 1), курсор, область
  прокрутки и сохранённый курсор. Он разбирает `\n` (как `\r\n`), `\r`, печатные символы с
  автопереносом и отложенным переносом, `ESC[r;cH`, `ESC[nA/B/G`, `ESC[K`, `ESC[2K`, `ESC[J`,
  `ESC[nM`, `ESC[t;br`, `ESC[r`, `ESC7`, `ESC8`; SGR и `ESC[?…h/l` пропускает. Эмулятор считает
  автопереносы, умеет отдавать сетку и историю текстом без ANSI и отвечает на `ESC[6n` строкой
  `ESC[<строка>;<колонка>R` по своему курсору.
- **Офлайн-модули.** Тест `e2e/expand-thinking.test.js` (node:test) запускается как
  `node --import tsx --test e2e/expand-thinking.test.js` и импортирует модули контроллера
  (экспортируемые имена — по коду): `tools/agentflow/screen.ts` и `tools/agentflow/mouse.ts` (включение
  с подставными потоками), `log.ts` (`log.thinking`, `log.info`), `status-panel.ts` (`panel.start`
  с фейковым stdout), `human.ts` (`new Human(false, io)` со сценарием `io`).
  - Фейковый stdout: `isTTY: true`, `rows: 30`, `columns: 120`, `write`, события `resize`. Всё, что в
    него пишется, подаётся в эмулятор.
  - Фейковый stdin: EventEmitter с `isTTY: true`, `setRawMode` (запоминает режим), `resume`, `pause`,
    `unref`. Ответ эмулятора на `ESC[6n` отправляется в stdin событием `data`.
  - Клик — `data` со строкой `ESC[<0;<x>;<y>M`, затем `ESC[<0;<x>;<y>m`. Колесо вверх — `ESC[<64;<x>;<y>M`.
    Строку для клика тест находит поиском текста в сетке эмулятора.
  - Таймеры (15 с колеса, ожидание ответа о позиции) — `mock.timers` из node:test.
  - Текст размышления T1240 — 1240 символов в 4 абзацах, известный тесту. Текст T40 занимает 40 строк по
    ширине окна, у каждой строки уникальный маркер `L01…L40`.
- **Mock-прогоны.** Копия kit с `git init` и начальным коммитом: mock создаёт ветку и worktree. Команда —
  `node tools/agentflow/bin/agentflow.mjs run tasks/01-slugify.md --mock --auto-approve --inject <точки>`,
  stdout в файл, stdin из `/dev/null`. Журнал — `.agentflow-runs/<run>/events.jsonl`, run id — из вывода.
- **Интерактивные сценарии** — псевдотерминал `e2e/helpers/pty-run.py` (`pty.fork`, 30×120, запуск
  `python3 -I`, ввод по таймеру или по появлению текста в выводе, запись сырого вывода). Если хелпера
  нет, его создаёт acceptance-tester. Хелпер отвечает на `ESC[6n` позицией курсора: ведёт ту же модель
  экрана, что `vt.js`, или вызывает его через `node`. После выхода прогона в том же pty выполняется
  `stty -a` и `echo typed-ok`, вывод тоже записывается.

## Evidence

- `e2e/evidence/expand-thinking.log` — вывод `node --test` модульных сценариев. Для сценариев с
  раскрытием в него же пишутся снимки сетки эмулятора до и после клика.

  отправленным вводом с отметками времени.

## Manual check

1. В копии kit в iTerm2 запусти
   `npm run agentflow -- run tasks/01-slugify.md --mock --auto-approve --inject think-long:implementer`.
   Пока идут размышления implementer, кликни по строке `▸ размышляет`: текст раскрылся под ней, лог
   ниже и панель на месте. Кликни ещё раз — свернулось.
2. Там же кликни по строке у верха экрана: текст обрезан, последней идёт `… ещё N строк — целиком в
   events.jsonl`, сама строка осталась на экране.
3. Покрути колесо вверх: после первого щелчка история прокручивается. Через 15 с клик снова раскрывает.
   ⌥+перетаскивание выделяет текст.
4. Нажми Ctrl+C во время размышлений: run остановлен. В shell набранное видно, клик и колесо работают
   как обычно.
5. В боевом прогоне на gigacode раскрой размышление spec-author или implementer и сверь его с блоком
   `thinking` этой сессии в `events.jsonl`.
