# Spec Delta

## MODIFIED Requirements

### Requirement: Остановка в BLOCKED
Контроллер SHALL останавливать run в BLOCKED с причиной в `state.json` и `ACCEPTANCE.md`, а не продолжать с допущением, когда нарушен контроль целостности: изменена замороженная спека, роль записала вне ACL или вызвала MCP вне allowlist, код изменился во время ревью, в change нет задач, freeze невозможен. Блокер роли SHALL открывать диалог блокера, и run останавливается, только если в нём выбрано «Остановить run».

#### Scenario: Изменена замороженная спека
- **WHEN** перед шагом apply digest спеки не совпадает с зафиксированным при freeze
- **THEN** run переходит в BLOCKED с причиной «замороженная спека изменена»

#### Scenario: Блокер роли
- **WHEN** финальное ревью вернуло BLOCKED
- **THEN** открывается диалог блокера, run остаётся в статусе running до решения человека
