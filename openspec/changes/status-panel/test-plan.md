# Test Plan

## Scope

Capability `pipeline-orchestration`, новые требования:

- «Панель статуса субагента»: сценарии «Работает субагент», «Продолжение сессии», «Номер запуска после resume».
- «Контекст прогона в панели»: «Петля и раунд», «Субагент завершился».
- «Живое время работы»: «Модель долго думает».
- «Панель не мешает диалогам»: «Диалог исчерпания лимита».
- «Когда панель выключена»: «Вывод в файл», «Флаг отключения».
- «Терминал восстанавливается на выходе»: «Ctrl+C во время работы субагента», «Изменение размера окна».

## Environment

- Kit в копии с `git init` и начальным коммитом: mock-прогон создаёт ветку и worktree.
  Команда: `node tools/agentflow/bin/agentflow.mjs run tasks/01-slugify.md --mock …`, роли
  только `--mock`.
- Интерактивный терминал эмулирует вспомогательный скрипт `e2e/helpers/pty-run.py`. Он
  запускает команду в псевдотерминале (`pty.fork`) с размером `TIOCSWINSZ` (по умолчанию 30×120),
  пишет весь сырой вывод в файл, умеет по таймеру менять размер (ioctl + `SIGWINCH`), отправлять
  `SIGINT` и вводить клавиши (`\r`, стрелки). Тест на `node:test` запускает его через `python3 -I`.
- Разбор сырого потока. Панель — это текст, который пишется после позиционирования курсора в
  одну из двух нижних строк (`ESC[<rows-1>;1H` / `ESC[<rows>;1H`). Область прокрутки — `ESC[<a>;<b>r`,
  сброс области — `ESC[r`. Ожидаемые модель и effort роли берутся из frontmatter `.qwen/agents/<роль>.md`,
  в mock к модели добавляется ` (mock)`.
- Ограничение mock: роли завершаются мгновенно. Поэтому «пока работает субагент» означает
  кадры панели между строкой `▶ субагент <роль>` и строкой `■ <роль> завершил` в сыром потоке.

## Evidence

Все доказательства лежат в `e2e/evidence/`:

- `*.raw` — сырой вывод псевдотерминала;
- `panel-agent.txt` — кадры панели, извлечённые из сырого потока: номер кадра, строки и текст без ANSI;
- `*.log` — вывод прогонов без pty;
- коды выхода записываются в первую строку соответствующего `.txt`/`.log`.

## Manual check

1. В обычном терминале выполни в копии kit
   `npm run agentflow -- run tasks/01-slugify.md --mock --auto-approve --inject all`. Внизу две
   строки панели, лог прокручивается над ними. После `✔ run … принят` prompt shell стоит под
   логом, а прокрутка работает во всю высоту.
2. Запусти `agentflow run <intent>` на gigacode. Пока spec-author работает, его время в панели
   растёт каждую секунду, даже когда лог стоит. Модель и effort совпадают со строкой `▶ субагент`.
3. Тот же mock-прогон без `--auto-approve`: в каждом диалоге панели нет, стрелки и Enter
   работают, после ответа панель возвращается.
4. Во время прогона измени размер окна: панель перерисовывается внизу без переносов. Нажми
   Ctrl+C: терминал в порядке, `reset` не нужен.
